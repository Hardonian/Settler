# Support

Thanks for using Settler.

## Getting Help

- **Documentation:** Start with `README.md` and `docs/QUICK_START.md`.
- **Issues:** Use the templates in `.github/ISSUE_TEMPLATE` for bugs or feature requests.
- **Questions:** If GitHub Discussions are enabled, use the Q&A category for how-to questions.

## Security Issues

Security vulnerabilities should be reported privately. See [SECURITY.md](SECURITY.md).
