3. **Exceptions are explained automatically**—you only pay for ones requiring manual review ($0.10 each)
4. **Complete audit trails** ensure compliance and defensibility

## 1-Page Narrative Memo

### What Settler Does
Settler is a reconciliation platform that automatically matches transactions between systems with deterministic guarantees. Instead of manual spreadsheets or custom code, Settler provides system-level enforcement that eliminates reconciliation risk.

### Who This Is For
Settler is for companies that:
- Process transactions across multiple systems (payment processors, e-commerce platforms, accounting systems)
- Need to reconcile transactions regularly (daily, weekly, monthly)
- Want to eliminate manual reconciliation work
- Require audit trails and compliance-ready infrastructure
- Want deterministic guarantees, not human promises

### Who This Is NOT For
Settler is NOT for:
- **Companies with single-system transactions** - If all your transactions are in one system, you don't need reconciliation
- **Companies with <100 transactions/month** - Manual spreadsheets are sufficient at this scale
- **Companies that don't care about accuracy** - Settler prioritizes deterministic guarantees over speed
- **Companies that want AI-powered matching** - Settler uses rule-based matching, not AI
- **Companies that need real-time reconciliation** - Settler processes reconciliations on a schedule (not real-time)
- **Companies that want 100% automated matching** - Some exceptions require manual review ($0.10 each)
- **Companies that need zero downtime** - Settler has standard SaaS uptime, not zero downtime guarantees

### Key Differentiators
1. **Deterministic guarantees** - Same inputs always produce same outputs
2. **System-level enforcement** - No human promises, automated matching
3. **Complete audit trails** - Every match is logged and auditable
4. **Simple pricing** - Pay per match, not per API call or AI token
5. **Compliance-ready** - SOC 2 Type II planned, complete audit trails

### Value Proposition
- **Eliminates $106K-$724K+ in annual risk** through system-level enforcement
- **Saves 7-42x vs building in-house** - No $50K-$500K+ development costs
- **Compliance-ready infrastructure** - Complete audit trails and deterministic guarantees
- **Simple, transparent pricing** - Pay per match, scales with your business

### Pricing Model
- **Starter:** $99/month for 10,000 reconciliations/month

Each plan includes 1% exception rate with automatic explanations. Exceptions beyond 1% requiring manual review cost $0.10 each.

- **vs Manual Spreadsheets:** Automated, scalable, eliminates errors

## Frequently Asked Questions

**Q: Is Settler real-time?**  
A: No. Settler processes reconciliations on a schedule (not real-time). This ensures deterministic guarantees and complete audit trails.

**Q: Is matching 100% accurate?**  
A: Settler provides deterministic guarantees—same inputs always produce same outputs. Some transactions can't be matched automatically and require manual review ($0.10 each).

**Q: Is Settler AI-powered?**  
A: No. Settler uses rule-based matching with deterministic guarantees, not AI. This ensures consistency and auditability.

**Q: Is Settler SOC 2 certified?**  
A: SOC 2 Type II is planned, not yet certified. We're building compliance-ready infrastructure with complete audit trails.

**Q: What happens if I exceed my plan's volume?**  
A: You'll be prompted to upgrade to a higher plan. This ensures you always have the capacity you need.

**Q: How much do exceptions cost?**  
A: Each plan includes 1% exception rate with automatic explanations. Exceptions beyond 1% requiring manual review cost $0.10 each.
