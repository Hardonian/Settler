## Operator Demo Flow (Reality-Backed)

1. Open **Control Plane** at `/console` (or legacy `/app`, which rewrites to console).
2. Inspect a recent run in **Run Explorer** (`/console/runs/:runId`).
3. Open **Truth Explorer** (`/console/proof-explorer`) for lineage + proof chain checks.
4. Pull trust artifacts from **Evidence Query Surface** (`/api/v1/runs/:id/evidence` and proof explorer run detail actions).
5. Inspect **Live Alerts** (`/console/alerts-view`) for incident context.
6. Replay the run in **Replay Engine** (`/console/replay`; `/app/replay` redirects) and compare hash outcomes.
7. Review tenant boundary controls in **Tenant Isolation Controls** (`/console/settings`; `/app/settings` legacy rewrite).
8. Inspect **Runtime Event Signals** (`/console/analytics`) for event-derived telemetry.

This sequence is intentionally constrained to implemented routes/endpoints in this repository.
