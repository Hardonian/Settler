# Settler.dev — Customer Communication Templates

**Version:** 1.0  
**Last Updated:** January 2026  
**Purpose:** Standardized customer communication templates for common scenarios

---

## Overview

This document provides templates for customer communications, including:
- Service outage notifications
- Performance degradation notifications
- Data recovery notifications
- Incident resolution notifications
- Pricing change notifications
- Security incident notifications

**Tone:** Professional, empathetic, transparent, actionable

---

## Template 1: Service Outage Notification

### Email Subject
```
[URGENT] Service Outage — Settler.dev — [Date]
```

### Email Body
```
Subject: Service Outage — [Service Name] — [Date]

Dear [Customer Name],

We're currently experiencing a service outage affecting [Service Name].

**Impact:**
- [Description of impact]
- [Affected functionality]
- [Estimated number of customers affected]

**Status:**
Our team is actively working to resolve this issue. We'll provide updates as we have more information.

**Updates:**
- [Time]: Incident detected
- [Time]: Investigation in progress
- [Time]: Fix deployed, monitoring

**Estimated Resolution:** [Time]

We apologize for the inconvenience and appreciate your patience.

For real-time updates, please check: https://settler.dev/status

Best regards,
Settler Support Team
```

## Communication Guidelines

### Timing

**Immediate (Within 15 Minutes):**
- Service outages (P0)
- Security incidents
- Data breaches

**Within 1 Hour:**
- Performance degradation (P1)
- Data loss incidents

**Within 4 Hours:**
- Minor issues (P2)
- Feature deprecations

**Within 24 Hours:**
- Maintenance windows
- Pricing changes
- Feature announcements

### Tone

**Professional:**
- Clear and concise
- Empathetic
- Transparent
- Actionable

**Avoid:**
- Technical jargon
- Blame
- Excuses
- Vague language

### Channels

**Email:**
- Service outages
- Security incidents
- Pricing changes
- Account issues

**Status Page:**
- Service outages
- Performance issues
- Maintenance windows

**In-App Notifications:**
- Feature announcements
- Maintenance windows
- Account updates

---

## Escalation

### When to Escalate

**Escalate to Leadership:**
- P0 incidents not resolved within 4 hours
- Security incidents
- Customer escalations
- Media inquiries

**Escalate to Legal:**
- Data breaches
- Legal compliance issues
- Customer legal threats

**Escalate to Security:**
- Security incidents
- Data breaches
- Unauthorized access
