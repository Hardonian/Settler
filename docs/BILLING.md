# Billing & Usage

Settler.dev uses usage-based billing with metered usage tracking.

## Usage Events

Usage is tracked for the following operations:

- **Recon Comparisons** - Each comparison between source and target
- **Validations** - Each validation rule execution
- **Transformations** - Each transformation recipe execution
- **Mappings** - Each field mapping operation
- **Workflow Steps** - Each step in a workflow chain
- **AI Tokens** - Token usage for AI operations
- **Audit Reports** - Each audit report generation
- **Storage** - Data storage in bytes
- **Webhook Triggers** - Each webhook delivery

### Enterprise - Custom

## Overage Rates

Overage is charged at the following rates:

- Recon comparisons: $0.01 per 1,000
- Validations: $0.005 per 1,000
- Transformations: $0.01 per 1,000
- Mappings: $0.005 per 1,000
- AI tokens: Varies by model
- Storage: $0.10 per GB/month
- Webhooks: $0.001 per webhook

## Stripe Integration

Usage is automatically synced to Stripe and included in monthly invoices.
