# Sales Qualification System

**Last Updated:** 2025-01-20  
**Status:** Revenue Bootstrap - Active  
**Purpose:** Replace intuition with structure - qualification checklist for sales

## Overview

This qualification system helps sales teams:

- **Qualify prospects:** Identify good-fit customers early
- **Disqualify bad fits:** Avoid wasted sales cycles
- **Prioritize leads:** Focus on high-value prospects
- **Track progress:** Monitor qualification metrics

**Philosophy:** Better to disqualify early than waste time on bad fits.

---

## Qualification Checklist

### Problem Clarity (Required)

**Question:** "What problem are you trying to solve?"

**Qualify if:**

- ✅ Clear problem statement (manual reconciliation, errors, time-consuming)
- ✅ Specific use case (Stripe + Shopify + QuickBooks reconciliation)
- ✅ Quantifiable pain (2+ days/month, 5%+ error rate)

**Disqualify if:**

- ❌ Vague problem ("we need better reconciliation")
- ❌ Wrong use case (single system, no multi-system reconciliation)
- ❌ No quantifiable pain ("it's fine, just slow")

**Score:** 1 point if qualified, 0 if disqualified

---

### Data Readiness (Required)

**Question:** "Do you have API access to your systems?"

**Qualify if:**

- ✅ API access available (Stripe, Shopify, QuickBooks APIs)
- ✅ Sample data available (at least 1K transactions)
- ✅ Technical capability (can integrate APIs)

**Disqualify if:**

- ❌ No API access (manual data entry only)
- ❌ No sample data (can't test)
- ❌ No technical capability (can't integrate)

**Score:** 1 point if qualified, 0 if disqualified

---

### Authority (Required)

**Question:** "Who makes budget decisions for tools like this?"

**Qualify if:**

- ✅ Decision maker involved (Finance Manager, CFO, Operations Lead)
- ✅ Budget authority confirmed ($100-$500/month approval)
- ✅ Timeline confirmed (decision within 30 days)

**Disqualify if:**

- ❌ No decision maker (individual contributor, no budget)
- ❌ No budget authority (needs approval from others)
- ❌ Long timeline (>90 days, no urgency)

**Score:** 1 point if qualified, 0 if disqualified

---

### Timeline (Required)

**Question:** "When do you need this solved?"

**Qualify if:**

- ✅ Urgent (within 30 days)
- ✅ Clear timeline (specific date or event)
- ✅ Budget approved or pending (likely to approve)

**Disqualify if:**

- ❌ No urgency ("someday", "exploring options")
- ❌ Long timeline (>90 days)
- ❌ No budget approved (unlikely to approve)

**Score:** 1 point if qualified, 0 if disqualified

---

### Budget Signal (Required)

**Question:** "What's your budget for reconciliation tools?"

**Qualify if:**

- ✅ Budget confirmed ($100-$500/month)
- ✅ Budget approved or pending (likely to approve)
- ✅ ROI understood (saves $2K-$5K/month in labor)

**Disqualify if:**

- ❌ No budget ($0, expecting free)
- ❌ Budget too low (<$50/month)
- ❌ Budget unclear (don't know, need to check)

**Score:** 1 point if qualified, 0 if disqualified

## Qualification Scoring

### Scoring System

- **Total Points:** 5 points maximum (1 point per criterion)
- **Qualification Threshold:** 4+ points (meet 4+ criteria)

### Qualification Levels

- **Highly Qualified (5 points):** All criteria met → Fast-track to pilot
- **Qualified (4 points):** Most criteria met → Standard pilot process
- **Marginally Qualified (3 points):** Some criteria met → Extended qualification
- **Disqualified (<3 points):** Few criteria met → Disqualify, don't waste time

## Discovery Questions

### Problem Discovery

1. "What's your current reconciliation process?"
2. "How long does reconciliation take?"
3. "What's your error rate?"
4. "What systems do you need to reconcile between?"

### Use Case Discovery

1. "What's your use case? (Stripe + Shopify + QuickBooks?)"
2. "How many transactions do you process per month?"
3. "What's your current volume?"
4. "Do you have multi-currency transactions?"

### Authority Discovery

1. "Who makes budget decisions for tools like this?"
2. "What's your budget approval process?"
3. "Who else needs to be involved in the decision?"
4. "What's your timeline for making a decision?"

### Budget Discovery

1. "What's your budget for reconciliation tools?"
2. "How do you justify tool purchases? (ROI, cost savings?)"
3. "What's your current cost? (labor, errors, time?)"
4. "What would make this a no-brainer purchase?"

## Objection Handling

### Objection: "We don't have API access"

**Response:** "Settler requires API access to your systems. If you don't have API access, we can help you set it up, or you might be better served by manual reconciliation tools. I'd be happy to reconnect when you have API access."

### Objection: "We're too small"

**Response:** "Settler is designed for companies doing 10K+ transactions/month. If you're smaller, manual reconciliation may be sufficient. I'd be happy to reconnect when you're processing more volume."

### Objection: "We already have a process"

**Response:** "If your current process works, great. Settler is for companies where reconciliation takes 2+ days/month and is error-prone. If that's not you, we may not be the right fit."

### Objection: "We need custom features"

**Response:** "Settler is a SaaS platform with standard integrations. If you need extensive custom development, we're not the right fit. I'd be happy to recommend custom development partners."

### Objection: "We need compliance certifications"

**Response:** "Settler is designed for e-commerce and SaaS companies. If you need HIPAA, FedRAMP, or other industry-specific certifications, we may not be the right fit. We can discuss Enterprise options if you're interested."

## Qualification Workflow

### Step 1: Initial Contact

- **Source:** Website signup, inbound inquiry, outbound outreach
- **Action:** Send discovery questions
- **Goal:** Understand problem, use case, authority

### Step 2: Discovery Call

- **Duration:** 30 minutes
- **Agenda:** Problem, use case, authority, timeline, budget
- **Goal:** Complete qualification checklist

### Step 3: Qualification Decision

- **Highly Qualified (5 points):** Fast-track to pilot
- **Qualified (4 points):** Standard pilot process
- **Marginally Qualified (3 points):** Extended qualification
- **Disqualified (<3 points):** Disqualify, don't waste time

### Step 4: Pilot Setup

- **Qualified Prospects:** Set up pilot (14-day trial)
- **Disqualified Prospects:** Polite rejection, reconnect later

## Qualification Metrics

### Key Metrics

- **Qualification Rate:** % of leads that qualify (target: 30%+)
- **Conversion Rate:** % of qualified leads that convert (target: 30%+)
- **Time-to-Qualify:** Days from contact to qualification (target: <7 days)
- **Disqualification Rate:** % of leads disqualified (target: 50%+)

### Tracking

- **CRM:** Track qualification scores in CRM
- **Dashboard:** Monitor qualification metrics
- **Review:** Weekly review of qualification performance
