| CLAIM_DETERMINISM            | Workflow execution is deterministic for identical inputs.                  | README + CLI replay/prove surfaces. | `workflow_hash(runA) == workflow_hash(runB)` for same execution seed.                   | `tests/determinism/determinism.test.mjs` and `settler prove`.                                                   | verified |

## Claims lacking verifiable invariants
