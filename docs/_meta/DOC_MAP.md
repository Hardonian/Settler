# Documentation Map

## External / primary entrypoints

- `README.md` — repository entry point.
- `docs/README.md` — docs hub.
- `docs/getting-started/` — setup and first-run.
- `docs/product/` — product-level capabilities and framing.
- `docs/reference/` + `docs/api/` — reference materials.

## Contributor / maintainer docs

- `docs/architecture/` — architecture and system boundaries.
- `docs/operations/`, `docs/runbook/`, `docs/sre/` — operational runbooks.
- `docs/security/`, `docs/compliance/` — security/compliance controls and expectations.
- `docs/deployment/` — deploy and environment flow.

## Internal strategy / GTM context

- `docs/strategy/`, `docs/strategic/`, `docs/gtm/`, `docs/go-to-market/`, `docs/marketing/`.

## Prompt assets

- Active prompt assets: `prompts/`
- Prompt governance and curation guidance: `docs/prompts/README.md`
- Historical/superseded prompt docs: `docs/archive/prompts/`

## Governance + traceability artifacts

- Inventory: `docs/_meta/doc-inventory.md`, `docs/_meta/doc-inventory.json`
- Overlap clusters: `docs/_meta/doc-clusters.md`
- Orphan candidates: `docs/_meta/orphan-docs.md`
- Archive index: `docs/_meta/archive-index.md`, `docs/_meta/archive-index.json`
- Consolidation changelog: `docs/_meta/DOCS_CONSOLIDATION_CHANGELOG.md`
