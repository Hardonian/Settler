# Settler One-Pager

## Problem

Financial reconciliations fail when pipelines are opaque and non-replayable.

## Approach

Compile policies into execution plans, meter every run, and emit cryptographic evidence bundles.

## Differentiation

Deterministic replay contract with policy-enforced runtime guards.

## Proof

Run `pnpm demo`; inspect `examples/demo-output` and replay with `pnpm settler:replay`.

## Get started

Use `pnpm verify:policy` to validate execution boundaries.
