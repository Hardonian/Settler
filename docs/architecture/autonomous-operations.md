# Autonomous Operations

Autonomous operations are generated by `buildPlatformOverview` using deterministic rules over tenant telemetry.

## Recommendations

Recommendations are emitted only when evidence exists:

- latency degradation => scaling recommendation with before/after evidence
- policy violation presence => policy misconfiguration recommendation
- recurring `QUEUE_LOCK_STALE` => reliability recommendation

## Controlled auto-remediation

Narrow, policy-governed actions are suggested:

- `retry_idempotent_jobs` (max retries: 3)
- `clear_stale_queue_locks` (max retries: 1)

These are recommendations, not blind execution. Action runners must enforce policy approval, audit logging, and tenant boundary checks.
