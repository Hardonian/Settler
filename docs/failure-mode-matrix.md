# Failure Mode Matrix

| Failure scenario             | Detection                                                        | Fallback behavior           | Machine-visible signal                                             | Operator action                                      |
| ---------------------------- | ---------------------------------------------------------------- | --------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------- |
| Kernel binary missing        | `resolveKernelRunner()` returns `fallback-ts` + `binary_missing` | TS hashing used             | `fallbackReason=binary_unavailable`; telemetry `binaryUnavailable` | Fix `SETTLER_KERNEL_BIN` or keep TS mode             |
| Kernel binary not executable | executable check failure                                         | TS hashing used             | `fallbackReason=binary_unavailable`                                | Restore execute permission                           |
| Kernel spawn failure         | process spawn error                                              | TS hashing used             | `fallbackReason=primary_kernel_failed`/classified reason           | Inspect binary/runtime dependencies                  |
| Kernel timeout               | request timeout kill                                             | TS hashing used             | telemetry `timeout`, fallback reason `timeout`                     | Increase timeout only after root-cause analysis      |
| Malformed kernel JSON        | parse failure                                                    | TS hashing used             | telemetry `malformedOutput`                                        | Validate kernel stdout contract                      |
| Protocol/version mismatch    | handshake/envelope validation failure                            | TS hashing used             | telemetry `versionMismatch`, reason `protocol_mismatch`            | Roll back kernel, verify compatibility               |
| Unsupported operation        | operation not in handshake support list                          | TS hashing used             | reason `unsupported_operation`                                     | Promote operation only after kernel support exists   |
| Hash divergence in shadow    | kernel hash != TS hash                                           | TS remains source of truth  | `divergence`, `hashMismatch`, divergence-by-operation              | Block primary promotion, investigate determinism gap |
| Global kernel disable        | `SETTLER_DISABLE_KERNEL=1`                                       | TS-only                     | runner `disabled`, reason `kernel_disabled`                        | Use for immediate rollback                           |
| Per-operation disable        | `SETTLER_DISABLE_OPERATION` contains operation                   | TS-only for operation       | reason `operation_disabled_env`                                    | Use for scoped rollback                              |
| Shadow-only rollout          | `SETTLER_KERNEL_SHADOW_ONLY=1`                                   | TS primary + kernel compare | mode `ts_with_shadow` and divergence fields                        | Safe canary before primary                           |
