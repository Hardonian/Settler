# AI Advisory Disclaimer - Settler

**Effective Date:** 2026-04-10  
**Status:** Policy - All Advisory Outputs

---

## 1. Purpose

This document establishes the disclaimer requirements for all AI-assisted advisory outputs generated by Settler, including reconciliation suggestions, anomaly detection, and rule recommendations.

---

## 2. Core Disclaimer

### Required Language

All AI-assisted outputs MUST include:

> **⚠️ ADVISORY ONLY - This is a non-authoritative recommendation. Every financial decision requires human review and approval. Settler does not provide accounting, tax, or legal advice.**

### Where Displayed

- UI: Banner above AI suggestions
- API: `X-Advisory-Disclaimer` header
- CLI: Prefix with `⚠️ ADVISORY:`
- Reports: Footnote on AI-assisted sections

---

## 3. Provenance Fields

Every AI response must include metadata:

```typescript
interface AIResponseMetadata {
  model: string;           // e.g., "claude-3-opus-20240229"
  version: string;         // e.g., "2024-02-29"
  timestamp: string;       // ISO 8601
  inputs_fingerprint: string; // Hash of input data
  confidence_score: number; // 0.0 - 1.0
  human_approval_required: boolean;
}
```

### Database Schema

```sql
CREATE TABLE ai_advisory_log (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  organization_id UUID REFERENCES organizations(id),
  run_id UUID REFERENCES reconciliation_runs(id),
  model VARCHAR(100) NOT NULL,
  version VARCHAR(50) NOT NULL,
  timestamp TIMESTAMPTZ NOT NULL DEFAULT now(),
  inputs_fingerprint VARCHAR(64) NOT NULL,
  confidence_score DECIMAL(3,2),
  human_approved BOOLEAN DEFAULT false,
  advisor_output JSONB,
  created_by UUID REFERENCES users(id)
);
```

## 4. Model Governance

### Allowed Use Cases

| Use Case | Approval Required | Disclaimer Required |
|----------|-------------------|-------------------|
| Suggest matching rules | No | Yes |
| Flag anomalies | No | Yes |
| Recommend tolerance | No | Yes |
| Generate audit summary | No | Yes |
| Predict cash flow | Yes | Yes |
| Classify transactions | No | Yes |
| Auto-approve matches | 🔴 FORBIDDEN | N/A |

### Prohibited Use Cases

**AI may NOT make autonomous decisions for:**

- Financial posting actions
- Reconciliation approvals without human review
- Refund disbursements
- Ledger corrections
- Any action involving fund movement
- Compliance attestations

## 5. Confidence Scoring

### Score Interpretation

| Score | Meaning | Action |
|-------|---------|--------|
| 0.90 - 1.00 | High confidence | Human review required |
| 0.70 - 0.89 | Medium confidence | Human review required |
| 0.50 - 0.69 | Low confidence | Human review required + flagged |
| < 0.50 | Very low confidence | Human review required + blocked |

### Score Factors

- Evidence availability (more evidence = higher)
- Historical accuracy of similar suggestions
- Rule maturity and usage count
- Data completeness

## 6. Human Approval Workflow

### Required Workflow

```
AI Suggestion Generated
        ↓
Display with Disclaimer + Confidence Score
        ↓
User Reviews (Owner/Admin/Developer)
        ↓
Explicit Approval (button click, not implied)
        ↓
Action Executed + Logged with approver ID
```

### Approval Requirements

- Must be a logged-in user with appropriate role
- Must explicitly click "Approve" (not auto-approved)
- Approval logged with:
  - User ID
  - Timestamp
  - Session ID
  - IP address

### Audit Trail

```sql
-- Every approval logged
INSERT INTO audit_logs (
  organization_id, user_id, action,
  target_type, target_id, metadata
) VALUES (
  @org_id, @user_id, 'AI_ADVISORY_APPROVED',
  'reconciliation_run', @run_id,
  '{"model": "...", "confidence": 0.85}'
);
```

## 7. Model Change Management

### Notification Requirements

When model/provider changes:

1. **Internal:** 7-day notice to team
2. **External:** 30-day notice to customers (Enterprise)
3. **Documentation:** Updated model version in metadata
4. **Validation:** Run validation suite on new model

### Rollback

- Maintain previous model for 30 days
- Feature flag for model selection
- Customer can request previous model (Enterprise)
