# Economics Evidence Boundary

No source-backed ARR, retention, churn, CAC, LTV, gross-margin, or customer-concentration history is
registered in the evidence room. Models and targets must not be presented as results.

Use `INVESTOR-RELATIONS-PRIVATE/EVIDENCE_REGISTER.md` for current financial evidence status. The
superseded scenario model is archived under `docs/archive/2026-09-21-evidence-audit/`.
