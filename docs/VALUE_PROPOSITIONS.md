# Value Propositions

**Last Updated:** 2025-01-20  
**Status:** Revenue Bootstrap - Active  
**Purpose:** Translate use cases into plain, boring language that resonates with each ICP

## Overview

Value propositions are **plain, boring, and demonstrable**. No buzzwords. No "AI-powered" unless unavoidable. Focus on **outcome + constraint**.

**Philosophy:** If you can't demonstrate it in-product, don't claim it.

---

## Value Proposition #1: E-commerce Finance Manager

### Headline

**"Stop spending 2 days every month reconciling payments. Automate it in 30 minutes."**

### Core Message

- **Problem:** Manual reconciliation takes 2-3 days/month, is error-prone, and doesn't scale
- **Solution:** Automated reconciliation via API, completes in <1 hour, 99%+ accuracy
- **Outcome:** Save 20-30 hours/month, reduce errors, improve audit readiness
- **Constraint:** Requires API access to Stripe, Shopify, QuickBooks (standard integrations)

### Key Points

1. **Time Savings:** 20-30 hours/month → <1 hour/month (95%+ reduction)
2. **Accuracy:** 5-10% mismatch rate → <1% mismatch rate (90%+ improvement)
3. **Cost Savings:** $2K-$5K/month in labor costs
4. **Scalability:** Handles 10K-1M+ transactions/month without additional effort
5. **Audit Trail:** Complete audit trail for compliance

### Proof Points

- **Demonstrable:** Reconciliation report showing matched/unmatched transactions
- **Measurable:** Time saved (vs manual process), accuracy (match rate), cost savings
- **Visible:** Console dashboard showing reconciliation status, match rate, time saved

### Messaging Tone

- **Plain:** "Automate payment reconciliation" (not "AI-powered reconciliation engine")
- **Boring:** "Save 20 hours/month" (not "transform your finance operations")
- **Specific:** "99%+ accuracy" (not "high accuracy")
- **Outcome-focused:** "Reduce errors" (not "leverage advanced algorithms")

### Objection Handling

- **"We don't have API access"** → "We support standard integrations. If you don't have API access, we can help you set it up."
- **"We're too small"** → "Settler is designed for companies doing 10K+ transactions/month. If you're smaller, manual reconciliation may be sufficient."
- **"We already have a process"** → "If your current process works, great. Settler is for companies where reconciliation takes 2+ days/month and is error-prone."

## Value Proposition #3: Accounting Firm Partner

## Summary

### Common Value Propositions Across ICPs

- **Time Savings:** 85-95% reduction (20-30 hours/month → <1 hour/month)
- **Accuracy:** 90%+ improvement (5-10% error rate → <1% error rate)
- **Cost Savings:** $1K-$5K/month in labor costs
- **Scalability:** Handles 10K-1M+ transactions/month without additional effort
- **Reliability:** 99%+ uptime, no maintenance burden

### Messaging Principles

- **Plain:** Use simple language, avoid buzzwords
- **Boring:** Focus on outcomes, not technology
- **Specific:** Use numbers, not vague claims
- **Outcome-focused:** Focus on what they get, not how it works
- **Demonstrable:** Every claim must be visible in-product
