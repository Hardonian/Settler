this directory. Prior materials were archived under
`docs/archive/2026-09-21-evidence-audit/investor/` because they mixed targets, simulations, and
unsupported claims with repository evidence.

Run `pnpm run verify:acquisition-readiness` before reviewing or releasing investor material.
