# Product Positioning

**Last Updated:** January 2026

This document outlines Settler's product positioning, tier ladder, and upgrade path to help investors understand the business model and growth strategy.

---

## Tier Ladder

Settler uses a **three-tier model** that creates a clear upgrade path from free/open source to enterprise:

```
┌─────────────────────────────────────────────────────────────┐
│                    ENTERPRISE TIER                          │
│  Custom Pricing | Unlimited Usage | SLA | Dedicated Support │
└─────────────────────────────────────────────────────────────┘
                            ↑
                    Natural Upgrade Path
                            ↑
┌─────────────────────────────────────────────────────────────┐
│                  PROFESSIONAL TIER                          │
│  $499/month | 1M reconciliations | Priority Support        │
└─────────────────────────────────────────────────────────────┘
                            ↑
                    Usage Growth Triggers Upgrade
                            ↑
┌─────────────────────────────────────────────────────────────┐
│                    STARTER TIER                              │
│  $99/month | 100K reconciliations | Email Support           │
└─────────────────────────────────────────────────────────────┘
                            ↑
                    Self-Serve Onboarding
                            ↑
┌─────────────────────────────────────────────────────────────┐
│                    OSS TIER (Free)                          │
│  MIT License | Core Protocol | Community Support            │
└─────────────────────────────────────────────────────────────┘
```

## Tier Details

### OSS Tier (Free)

**Target:** Individual developers, small projects, evaluation

**Value Proposition:**
- Free forever
- Core protocol types and utilities
- Basic React components
- Community support
- MIT License (no restrictions)

**Purpose:**
- Build developer community
- Enable evaluation and experimentation
- Create network effects
- Generate leads for paid tiers

**Upgrade Triggers:**
- Need platform integrations (Shopify, Stripe, etc.)
- Need advanced features (virtualization, telemetry)
- Need production support
- Need enterprise features (SSO, RBAC)

---

### Starter Tier ($99/month)

**Target:** Small businesses, startups, side projects

**Value Proposition:**
- Affordable entry point
- Production-ready reconciliation
- Receipt parsing (10K/month)
- Feature flags (1M evaluations/month)
- Email support (48-hour response)

**Use Cases:**
- E-commerce stores (Shopify, WooCommerce)
- Small SaaS companies
- Freelancers/consultants

**Upgrade Triggers:**
- Usage exceeds tier limits (100K reconciliations/month)
- Need faster support response
- Need priority features

---

### Professional Tier ($499/month)

**Target:** Growing businesses, established SaaS companies

**Value Proposition:**
- Higher usage limits (1M reconciliations/month)
- Priority support (24-hour response)
- Advanced features
- Production SLA (99.9% uptime)

**Use Cases:**
- Mid-market SaaS companies
- E-commerce platforms (100+ orders/day)
- Marketplaces with multi-party transactions

**Upgrade Triggers:**
- Need unlimited usage
- Need SLA guarantees (99.99%)
- Need dedicated support
- Need custom integrations
- Need SSO/RBAC

---

### Enterprise Tier (Custom Pricing)

**Target:** Large organizations, regulated industries

**Value Proposition:**
- Unlimited usage
- SLA guarantees (99.99% uptime)
- Dedicated support (24/7)
- Custom integrations
- SSO, RBAC, white-label
- Data residency options
- Compliance certifications

**Use Cases:**
- Enterprise SaaS companies
- Financial services
- Healthcare (HIPAA)
- Government contracts

**Pricing:** Custom ($5K-$50K+/year depending on requirements)

## Positioning Strategy

### Against Legacy Solutions

**Positioning:** Modern, developer-first alternative to legacy ERP systems

**Key Messages:**
- ✅ API-first, self-serve (vs. complex, consultant-heavy)
- ✅ Fast implementation (days vs. months)
- ✅ Lower cost (subscription vs. license + maintenance)
- ✅ Better developer experience

### Against Point Solutions

**Positioning:** Comprehensive reconciliation platform (not vendor-locked)

**Key Messages:**
- ✅ Multi-system reconciliation (not single-vendor)
- ✅ Comprehensive audit trails
- ✅ Enterprise-grade security and compliance
- ✅ Flexible, adaptable to business needs

### Against Custom Solutions

**Positioning:** Faster, cheaper, better-maintained than building in-house

**Key Messages:**
- ✅ Faster time-to-market (weeks vs. months/years)
- ✅ Lower total cost of ownership
- ✅ Ongoing maintenance and updates
- ✅ Best practices built-in

## Growth Strategy

### Bottom-Up (OSS → Paid)

1. **Developer Adoption:** OSS components create awareness and trust
2. **Self-Serve Onboarding:** Easy signup, Developer Console access
3. **Value Demonstration:** Quick wins, clear ROI
4. **Natural Upgrades:** Usage growth triggers upgrades

### Top-Down (Enterprise Sales)

1. **Target Accounts:** Identify high-value prospects
2. **Custom Demos:** Tailored demonstrations
3. **Compliance Support:** Help with SOC 2, GDPR, etc.
4. **Custom Contracts:** Negotiate terms and pricing

### Expansion Revenue

1. **Usage Growth:** Natural expansion as customers grow
2. **Feature Adoption:** New features drive upgrades
3. **Professional Services:** Optional consulting and training
4. **Multi-Product:** Future products (beyond reconciliation)

## Competitive Advantages

### Technical

- **Event-Sourced Architecture:** Immutable audit trail, time-travel debugging
- **Deterministic Math:** No floating-point errors, currency accuracy
- **Developer-First:** Comprehensive SDKs, CLI, Developer Console

### Operational

- **Network Effects:** More integrations → more value → more customers
- **Data Advantage:** Reconciliation patterns improve with scale
- **Compliance Expertise:** SOC 2, GDPR, PCI-DSS built-in
- **Developer Experience:** Best-in-class documentation and tooling
