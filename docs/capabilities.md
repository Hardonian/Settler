# Settler Capability Registry (Canonical)

> Back to platform truth index: [`docs/platform-index.md`](./platform-index.md)

This registry is the canonical map of platform capabilities and where they surface.

| Capability                                   | Subsystem                           | Kernel operation         | CLI command / script                                                    | Console surface                                                     | Enterprise relevance                       | Docs location                                                                     |
| -------------------------------------------- | ----------------------------------- | ------------------------ | ----------------------------------------------------------------------- | ------------------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------------- |

| Replay verification                          | CLI + verification workflows        | `proof_bundle_hash`      | `pnpm replay:run`, `pnpm verify:test-data`                              | Replay/proof investigation views                                    | Required for enterprise assurance          | `docs/replay/README.md`, `docs/verify/QUICKSTART.md`                              |
| Artifact identity hashing                    | CLI + kernel boundary               | `artifact_identity_hash` | `pnpm test:reconciliation:e2e`                                          | Proof explorer lineage                                              | Supports enterprise provenance guarantees  | `docs/architecture/rust-kernel-boundary.md`                                       |
| API control plane (tenancy/auth/idempotency) | `packages/api`                      | none (TS boundary)       | `pnpm dev:stack` (API), `pnpm verify`                                   | Admin and operator console APIs                                     | Required for enterprise boundary controls  | `docs/architecture/platform-architecture.md`, `docs/api/README.md`                |
| Operator diagnostics                         | CLI + scripts                       | none                     | `pnpm doctor`, `pnpm run settler:doctor -- --json`, `pnpm suite-doctor` | Operations/support + `/console/diagnostics`, `/console/setup-check` | Important for enterprise SLAs              | `docs/operations/README.md`, `docs/support/doctor-and-health-checks.md`           |

## Notes

- Kernel operations are intentionally scoped to deterministic compute primitives; tenancy/auth/persistence remain in TypeScript control plane.
- Capabilities without direct kernel operations still require deterministic evidence and clear operational fallback paths.
