## Tier Ladder

Settler offers a clear progression from open-source protocol to managed platform to enterprise solution:

### Tier 1: OSS Protocol (Free)

**What:** Core protocol types and basic React components  
**License:** MIT License  
**Target:** Developers building custom solutions  
**Value:** Foundation for building reconciliation solutions

**Includes:**

- `@settler/protocol` - Core types and interfaces
- React.Settler OSS components
- Basic validation and security

**Upgrade Path:** Commercial features, managed platform

---

### Tier 2: Commercial Features ($99/month)

**What:** Advanced React.Settler features requiring subscription  
**License:** Commercial License  
**Target:** Teams needing advanced features  
**Value:** Platform integrations, advanced telemetry, audit logging

**Includes:**

- All OSS features
- Platform integrations (Shopify, Stripe, MCP)
- Virtualized tables
- Advanced telemetry
- Audit logging
- Webhook manager

**Upgrade Path:** Managed platform (Settler Enterprise API)

---

### Tier 3: Managed Platform (SaaS)

**What:** Settler Enterprise API - Open Source Reconciliation Engine  
**License:** Proprietary SaaS  
**Target:** Companies wanting managed solution  
**Value:** No infrastructure management, automatic scaling, support

**Includes:**

- Reconciliation Engine API
- Receipts API
- Feature Flags API
- Developer Console
- Usage analytics
- Billing management

**Tiers:**

- **Starter:** $99/month (100K reconciliations/month)
- **Professional:** $499/month (1M reconciliations/month)
- **Enterprise:** Custom (unlimited usage)

**Upgrade Path:** Enterprise features (SSO, RBAC, custom integrations)

---

### Tier 4: Enterprise (Custom)

**What:** Enterprise features and custom contracts  
**License:** Enterprise Agreement  
**Target:** Large enterprises with custom requirements  
**Value:** SLA guarantees, dedicated support, custom integrations

**Includes:**

- All platform features
- SSO and RBAC
- Custom integrations
- White-label options
- Dedicated support (24/7)
- SLA guarantees
- Self-hosting options (negotiable)

---

## Upgrade Path & Value

### OSS → Commercial

**Trigger:** Need for platform integrations or advanced features  
**Value:** Access to Shopify, Stripe, MCP integrations  
**Barrier:** $99/month subscription

### Commercial → Managed Platform

**Trigger:** Want managed solution, no infrastructure management  
**Value:** No server management, automatic scaling, support  
**Barrier:** Migration effort, API adoption

### Managed Platform → Enterprise

**Trigger:** Need SSO, RBAC, custom integrations, SLA  
**Value:** Enterprise features, dedicated support, custom contracts  
**Barrier:** Custom pricing, contract negotiation
