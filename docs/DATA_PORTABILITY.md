# Data Portability Terms - Settler

**Effective Date:** 2026-04-10  
**Status:** Contract Commitment

---

## 1. Commitment

Settler is committed to customer data ownership and portability. Customers can export all their data at any time in standard formats.

---

## 2. Export Capabilities

### Available Export Methods

| Method | Format | Latency | Cost |
|--------|--------|---------|------|
| API | JSON | Real-time | Free (within quota) |
| CSV Export | CSV | Real-time | Free |
| Bulk Export | JSON/CSV | 24 hours | Free |
| DB Snapshot | PostgreSQL dump | 48 hours | $100 |

### Export via API

```bash
# Organization data export
GET /api/v1/organizations/{id}/export
Authorization: Bearer {token}

Response:
{
  "export_id": "exp_xxx",
  "status": "processing",
  "download_url": "https://...",
  "expires_at": "2026-04-11T..."
}
```

### Export via Console

1. Navigate to Organization Settings → Data Export
2. Select data types:
   - Reconciliation runs + evidence
   - Transaction records
   - Audit logs
   - User data
   - Integration configs
3. Click "Export"
4. Download when ready
