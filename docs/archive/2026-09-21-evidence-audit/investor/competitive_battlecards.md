## Battlecard #1: BlackLine

### Profile

| Attribute          | Detail                                                                          |
| ------------------ | ------------------------------------------------------------------------------- |
| **Category**       | Enterprise financial close management                                           |
| **Founded**        | 2001 (Los Angeles, CA)                                                          |
| **Public/Private** | Public (NASDAQ: BL). Acquired by Thoma Bravo (Dec 2024) for ~$4.5B.             |
| **Target market**  | Fortune 500, large enterprises, 1,000+ employees                                |
| **Pricing**        | Custom — $77,000–$340,000+/year (estimated). No self-service.                   |
| **Implementation** | 3–6 months, requires professional services                                      |
| **Products**       | Account reconciliation, close management, journal entry, matching, intercompany |

### When an Investor Asks: "What if BlackLine moves down-market?"

> **Answer:** "BlackLine's average deal is $200K+/year. Their entire business model — field sales, implementation teams, professional services margin — depends on enterprise contract sizes. Moving to $99/month deals would destroy their unit economics. They'd need to rebuild their GTM, retrain their sales team, and cannibalize their own pipeline. It's the classic innovator's dilemma — they can't move down without damaging what's working."

### Head-to-Head

| Dimension                | BlackLine              | Settler                                  |
| ------------------------ | ---------------------- | ---------------------------------------- |
| **Price**                | $77K–$340K/yr          | $348–$5,988/yr                           |
| **Time to value**        | 3–6 months             | < 1 day                                  |
| **Target**               | Fortune 500            | SMB / Mid-market                         |
| **Self-service**         | No                     | Yes                                      |
| **API-first**            | No                     | Yes                                      |
| **Proofpack evidence**   | No (reports/exports)   | Yes (hash-linked)                        |
| **Institutional memory** | No                     | Yes (rules engine with success tracking) |
| **AI/determinism**       | AI features (newer)    | Deterministic-first, AI optional         |
| **Implementation cost**  | $20K–$100K             | $0                                       |
| **Switching cost**       | Contractual + workflow | Operational (data gravity)               |

### Key Takeaway

BlackLine is not a competitor — it's a different market segment. Settler competes for the 90% of companies that can't afford or justify BlackLine. If Settler succeeds at scale, BlackLine may become a future acquirer.

## Battlecard #2: FloQast

### Profile

| Attribute          | Detail                                                                |
| ------------------ | --------------------------------------------------------------------- |
| **Category**       | Accounting workflow / close management                                |
| **Founded**        | 2013 (Los Angeles, CA)                                                |
| **Public/Private** | Private. ~$200M raised (Series D, 2021).                              |
| **Target market**  | Mid-market accounting teams, 100–5,000 employees                      |
| **Pricing**        | ~$999/month starting (custom quotes, annual contracts)                |
| **Implementation** | 2–4 weeks with dedicated onboarding                                   |
| **Products**       | Close management, AutoRec (reconciliation), Flux Analysis, compliance |

### When an Investor Asks: "Isn't FloQast the competitor?"

> **Answer:** "FloQast is the closest competitor by market segment — they serve mid-market accounting teams. But FloQast is a close management platform that added reconciliation as a feature (AutoRec). Settler is reconciliation-native. FloQast doesn't generate proofpacks, doesn't track rule success rates, and doesn't build institutional memory across runs. Also, FloQast starts at ~$999/month — Settler starts at $29."

### Head-to-Head

| Dimension                | FloQast                               | Settler                                |
| ------------------------ | ------------------------------------- | -------------------------------------- |
| **Price**                | ~$999/mo+                             | $29–$499/mo                            |
| **Core focus**           | Close management (recon is a feature) | Reconciliation (close is out of scope) |
| **Time to value**        | 2–4 weeks                             | < 1 day                                |
| **Target**               | Accounting teams                      | Finance ops + developers               |
| **API-first**            | No                                    | Yes                                    |
| **Proofpack evidence**   | No                                    | Yes                                    |
| **Institutional memory** | No                                    | Yes                                    |
| **ERP integration**      | Strong (NetSuite, Sage, etc.)         | Early (NetSuite, Xero, QuickBooks)     |
| **Self-service**         | No                                    | Yes                                    |
| **Pricing model**        | Per-entity, annual contract           | Usage-based, monthly                   |

### Where FloQast Wins

- Brand recognition in accounting circles
- Deeper ERP integrations
- Close management features (checklists, review workflows, flux analysis)
- Established customer base and case studies

### Where Settler Wins

- 10x cheaper entry point
- Reconciliation depth (proofpacks, institutional memory, cross-run intelligence)
- Developer/API-first experience
- Self-service onboarding
- Usage-based pricing (no annual lock-in)
- Deterministic, replayable results

## Battlecard #3: ReconArt

### Profile

| Attribute          | Detail                                                                                 |
| ------------------ | -------------------------------------------------------------------------------------- |
| **Category**       | Dedicated reconciliation platform                                                      |
| **Founded**        | 2007 (Bulgaria / Global)                                                               |
| **Public/Private** | Private                                                                                |
| **Target market**  | Mid-market to enterprise, financial institutions                                       |
| **Pricing**        | ~$300/month starting (custom, annual)                                                  |
| **Implementation** | 1–4 weeks depending on complexity                                                      |
| **Products**       | Account reconciliation, transaction matching, balance sheet reconciliation, compliance |

### When an Investor Asks: "ReconArt is a direct recon competitor — how do you differentiate?"

> **Answer:** "ReconArt is the closest direct competitor — they're reconciliation-focused and serve mid-market. But ReconArt is a traditional enterprise software company. No public API, no self-service, no proofpack evidence, no institutional memory. Their matching is rules-based but doesn't track rule performance or improve over time. And their pricing is opaque — Settler's usage-based model is transparent and self-serve."

### Head-to-Head

| Dimension                     | ReconArt                  | Settler                         |
| ----------------------------- | ------------------------- | ------------------------------- |
| **Price**                     | ~$300/mo+ (custom)        | $29–$499/mo (transparent)       |
| **Core focus**                | Reconciliation            | Reconciliation                  |
| **API-first**                 | No                        | Yes                             |
| **Self-service**              | No                        | Yes                             |
| **Proofpack evidence**        | No (reports)              | Yes (hash-linked)               |
| **Institutional memory**      | No                        | Yes                             |
| **Rule performance tracking** | No                        | Yes (match_count, success_rate) |
| **Deployment**                | Cloud or on-premise       | Cloud (SaaS)                    |
| **Target**                    | Traditional finance teams | Finance + ops + developers      |
| **Modern UX**                 | Legacy-feeling            | Modern (Next.js)                |

### Key Takeaway

ReconArt is the most relevant direct competitor. Settler differentiates on (1) proofpack evidence, (2) institutional memory / rules engine, (3) API-first developer experience, (4) transparent usage-based pricing, and (5) modern self-service UX.

## Battlecard #5: Spreadsheets / Manual Process

### Profile

| Attribute          | Detail                                                             |
| ------------------ | ------------------------------------------------------------------ |
| **Category**       | Default approach for 94% of teams                                  |
| **"Pricing"**      | $0 (software) + $400–$3,000/month (labor)                          |
| **Implementation** | N/A — already in use                                               |
| **Why teams stay** | Familiarity, perceived control, no budget approval needed, inertia |

### When an Investor Asks: "Why would anyone switch from free spreadsheets?"

> **Answer:** "Spreadsheets aren't free — they cost $400 to $3,000/month in labor. They just hide the cost in headcount. Settler at $99/month replaces $600–$1,650/month of that labor with a 400–1,000% ROI. The real question is: why would a finance team keep spending 20–50 hours/month on something a system can do in 15 minutes?"

### Head-to-Head

| Dimension                  | Spreadsheets               | Settler                                      |
| -------------------------- | -------------------------- | -------------------------------------------- |
| **Monthly cost (total)**   | $400–$3,000 (labor)        | $29–$499 (software) + $50–$200 (review time) |
| **Audit trail**            | None                       | Complete (proofpacks)                        |
| **Matching**               | Manual human matching      | Automated deterministic                      |
| **Exception tracking**     | Email / memory             | Structured queue with history                |
| **Institutional memory**   | In people's heads          | In the system                                |
| **Scales with volume**     | No (linear labor)          | Yes (automated)                              |
| **Error rate**             | High                       | Near-zero (deterministic)                    |
| **Employee turnover risk** | High (knowledge walks out) | None (system retains)                        |
| **Time to complete**       | 20–50 hours                | 1–4 hours (review only)                      |

### Sales Objection Handling

| Objection                          | Response                                                                                                                |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| "We've always done it in Excel"    | "And it costs you $X/month in labor. Settler costs $99. The spreadsheet isn't free — it's just hiding in your payroll." |
| "Our process works fine"           | "How long does your month-end close take? If it's more than 3 days, reconciliation is likely the bottleneck."           |
| "I don't want to learn a new tool" | "First reconciliation run takes 15 minutes. You already know how to read a match report."                               |
| "What if Settler goes away?"       | "Every proofpack is yours — exportable, verifiable, portable. Your data never locks in."                                |
| "We don't have budget"             | "You're already spending $X00/month on labor. This saves money — it doesn't cost money."                                |
