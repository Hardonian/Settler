# Front-End Route Index

## Marketing

- `/` (Homepage): Main landing page. Positioning: "API infrastructure for financial evidence".
- `/pricing`: Pricing tiers and features.
- `/why-settler`: Core value proposition and "Why Us".
- `/proof`: Social proof, trust signals, and case studies.
- `/architecture`: Technical deep dive into the system design.
- `/benchmarks`: Performance metrics and comparisons.
- `/roadmap`: Product roadmap and future features.
- `/vision`: Long-term vision and mission.
- `/founder`: Founder story / letter.
- `/security`: Security posture, compliance (SOC2, etc.), and trust.
- `/status`: System status and uptime history.
- `/comparison`: Competitor comparison page.
- `/how-it-works`: Functional explanation of the platform.
- `/community`: Community resources and engagement.
- `/receipts`: Product specific landing for Receipts.
- `/feature-flags`: Product specific landing for Feature Flags.
- `/edge-ai`: Product specific landing for Edge AI (if active).
- `/changelog`: Release notes and updates.
- `/legal/terms`: Terms of Service.
- `/legal/privacy`: Privacy Policy.
- `/legal/dpa`: Data Processing Agreement.

## Documentation

- `/docs`: Documentation home.
- `/docs/api`: API Reference.
- `/docs/cli`: CLI Reference and guides.
- `/docs/sdk`: SDK documentation.
- `/docs/quickstart`: specific getting started guides.

## Console / App

- `/console`: Main user dashboard.
- `/console/api-keys`: API key creation and management.
- `/console/billing`: Plan management and invoices.
- `/console/usage`: Usage metrics and limits.
- `/console/receipts`: Receipts management interface.
- `/console/feature-flags`: Feature flags management interface.
- `/console/playground`: Interactive API playgrounds (Convert, Flags, Receipts, Reconcile).
- `/signup`: User registration flow.
- `/realtime-dashboard`: Live metrics view.

## Internal / Ops

- `/console/site`: CMS/Site builder for dynamic pages (internal tool).
