# OSS Repository Information Archive

This directory contains information about the open-source (OSS) version of Settler that should be used for the `settler-oss` repository.

## Contents

- **OSS_REPO_READY.md** - OSS repository setup status and instructions
- **OPEN_CORE_READY_TO_MERGE.md** - Open-core architecture implementation details
- **OSS_MIRROR_SETUP.md** - Mirror publishing setup guide
- **OSS_REPO_MANUAL_SETUP.md** - Manual setup instructions
- **OSS_REPO_NEXT_STEPS.md** - Next steps for OSS repo
- **OSS_REPO_SETUP_COMPLETE.md** - Setup completion report
- **OSS_REPO_STATUS.md** - Current status of OSS repo

## SDK Packages (for settler-oss)

The following packages should be included in the OSS repository:

- `packages/sdk` - Official Node.js/TypeScript SDK
- `packages/sdk-python` - Official Python SDK
- `packages/sdk-go` - Official Go SDK
- `packages/sdk-ruby` - Official Ruby SDK
- `packages/cli` - Command-line tool
- `packages/react-settler` - React components
- `packages/protocol` - Protocol types
- `packages/adapters` - Adapter implementations

## Excluded from OSS

The following should NOT be included in settler-oss:

- `packages/api` - Core API server (proprietary)
- `packages/web` - Web application and Console (proprietary)
- Internal documentation
- Proprietary features
- Secrets or credentials
