## Next Steps (For Production Use)

### 1. Run Production Introspection

When you have `DATABASE_URL` pointing to production:

```bash
DATABASE_URL="your-production-url" npm run verify:schema-introspect
```

This will generate `supabase/production-schema.json` with the actual production state.

### 2. Verify Golden Migration

Test the golden migration on a clean database:

```bash
# First run
psql $DATABASE_URL -f supabase/migrations/00000000_settler_golden_schema.sql

# Second run (should cause zero changes - proves idempotency)
psql $DATABASE_URL -f supabase/migrations/00000000_settler_golden_schema.sql
```

### 3. Configure CI Secrets

Add to GitHub Actions secrets:
- `DATABASE_URL`: Production database connection string
- `SUPABASE_URL`: Supabase project URL
- `SUPABASE_SERVICE_ROLE_KEY`: Service role key

### 4. Run Full Verification

```bash
npm run verify:production-parity
```
