# Completed Scripts Archive

This directory contains copies of scripts that have been successfully executed.

## Purpose

Scripts are archived here after successful execution to:
1. Keep a historical record of what has been run
2. Allow easy reference to past script executions
3. Keep the main scripts directory clean

## Naming Convention

Archived scripts are named with the format:
`[script-name]_[timestamp].[ext]`

The timestamp format is: `YYYYMMDD_HHMMSS`

## Note

These are copies for reference. The original scripts remain in the `scripts/` directory but are marked as executed in `.migration-execution-log.json`.
