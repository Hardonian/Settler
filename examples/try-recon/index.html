🚀 Try Recon - Interactive Setup

Get started with Settler.dev in 5 minutes

Step 1: Get Your API Key

Sign up at app.settler.io to get your API key.

Step 2: Create a Reconciliation Job

const job = await fetch('https://api.settler.io/api/v1/recon/jobs', { method: 'POST', headers: { 'X-API-Key': 'YOUR_API_KEY', 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'My First Reconciliation', sourceAdapter: 'stripe', targetAdapter: 'internal_ledger', reconStrategy: 'deterministic' }) }); const jobData = await job.json(); console.log('Job created:', jobData);

Step 3: Execute Reconciliation

const result = await fetch(`https://api.settler.io/api/v1/recon/jobs/${jobId}/execute`, { method: 'POST', headers: { 'X-API-Key': 'YOUR_API_KEY', 'Content-Type': 'application/json' } }); const resultData = await result.json(); console.log('Reconciliation complete:', resultData);

Step 4: View Results

const results = await fetch(`https://api.settler.io/api/v1/recon/jobs/${jobId}/results`, { headers: { 'X-API-Key': 'YOUR_API_KEY' } }); const resultsData = await results.json(); console.log('Results:', resultsData);
