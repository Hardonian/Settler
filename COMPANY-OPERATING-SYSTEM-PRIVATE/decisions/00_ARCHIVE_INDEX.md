# Decisions Archive

**This folder contains all codified decisions.**

## Purpose

- Preserve decision context and rationale
- Avoid revisiting settled questions
- Track evolution of thinking
- Enable accountability

## Categories

- `pricing/` — Pricing decisions
- `legal-commercial/` — Contract and legal decisions
- `product/` — Product decisions
- `technical/` — Architecture and technology
- `operations/` — Process and tooling
- `strategy/` — Strategic choices

## Naming Convention

```
YYYY-MM-DD_CATEGORY_SHORT-TITLE.md
```

## Process

See `README.md` in this folder for full decision logging process.

## Status

**Append-only** — Never delete historical decisions.
