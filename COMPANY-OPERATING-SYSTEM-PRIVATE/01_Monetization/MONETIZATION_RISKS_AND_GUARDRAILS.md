# Monetization Risks and Guardrails

| Risk               | Failure mode                   | Guardrail                             |
| ------------------ | ------------------------------ | ------------------------------------- |
| Underpricing       | high delivery load, low margin | discount floors + deal desk approvals |
| Over-customization | delivery sprawl                | custom scope only via SOW             |
| Founder exceptions | inconsistent precedent         | mandatory exception register          |
| Pricing complexity | billing errors/confusion       | SKU map and limited dimensions        |
| Pilot abuse        | endless unpaid effort          | pilot end-date + conversion criteria  |
| Support overhang   | premium support on low ACV     | support tiers with strict boundaries  |

## Trust-preserving rule

Never price in ways that incentivize hiding exceptions, suppressing evidence, or misclassifying usage.
