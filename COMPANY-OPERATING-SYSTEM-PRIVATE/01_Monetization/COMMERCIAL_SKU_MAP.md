# Commercial SKU Map

| Internal SKU          | Offer Type     | Billing Behavior   | Entitlement Concept              | Contract Artifact              |
| --------------------- | -------------- | ------------------ | -------------------------------- | ------------------------------ |
| SETTLER-STARTER-MTH   | Subscription   | Monthly recurring  | Starter limits and support       | Click-through / standard order |
| SETTLER-GROWTH-MTH    | Subscription   | Monthly recurring  | Growth limits + priority support | Order form optional            |
| SETTLER-ENT-ANN       | Subscription   | Annual invoiced    | Enterprise baseline entitlements | MSA + Order Form               |
| SETTLER-IMP-STD       | Implementation | One-time fixed fee | Implementation milestones only   | SOW or order form schedule     |
| SETTLER-SERV-CUSTOM   | Services       | T&M or milestone   | No product entitlements          | SOW required                   |
| SETTLER-USAGE-OVERAGE | Usage          | Arrears monthly    | Metered overages                 | Order form pricing schedule    |

## Naming stability rules

- SKU code never changes once sold.
- Marketing names can evolve; SKU remains canonical for finance and contracts.
- Any new SKU requires updates to pricing governance, COA mapping, and system-of-record map.
