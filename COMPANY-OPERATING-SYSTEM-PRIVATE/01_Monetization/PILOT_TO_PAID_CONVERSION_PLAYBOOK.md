# Pilot to Paid Conversion Playbook

## Run a pilot when

- Buyer needs proof of operational fit.
- Integration complexity is moderate/high.
- Buyer has active budget path and executive sponsor.

## Do not run a pilot when

- No champion or no decision timeline.
- Prospect asks for free custom build work.
- Success criteria cannot be measured.

## Entry criteria

- Defined use case and data source availability
- Named business owner + technical owner
- Agreed success metrics and end date

## Success criteria

- First reconciliation completed
- Exception workflow used by operator
- Evidence/proofpack reviewed with buyer stakeholders
- Commercial next step scheduled before pilot end

## Conversion evidence required

- Before/after workflow data
- Time saved or error-risk reduced
- Exception-resolution quality metrics

## Timing and handoff

- Mid-pilot checkpoint day 7
- Conversion review by day 12-14 (or day 21 for enterprise)
- Handoff Sales -> Implementation owner -> CS owner

## Red flags

- Scope creep without agreement
- Procurement blockers discovered too late
- "Need more time" with no additional workplan
