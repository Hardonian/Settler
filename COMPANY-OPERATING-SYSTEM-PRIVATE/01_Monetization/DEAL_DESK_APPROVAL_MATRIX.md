# Deal Desk Approval Matrix

| Request Type             | Auto-approvable      | Escalated                     | Disallowed                              |
| ------------------------ | -------------------- | ----------------------------- | --------------------------------------- |
| Subscription discount    | <=10%                | 11-20% founder                | >30% without strategic memo             |
| Implementation giveaway  | None                 | <=20% value with founder      | Full waiver for non-strategic deals     |
| Custom security language | Standard addendum    | medium-risk with legal review | unlimited liability/security guarantees |
| Invoice terms            | Net-30               | Net-45 founder                | Net-90                                  |
| Procurement concession   | standard packet only | added artifact with owner     | bespoke audits without capacity         |
| Support exception        | tier standard        | temporary upgrade with expiry | perpetual premium support on low plan   |
| Pilot extension          | none                 | one 14-day extension          | repeated open-ended pilot               |
| Special usage caps       | standard SKU         | temporary cap with expiry     | uncapped usage with capped fee          |

## Founder-mode path

Revenue owner -> Founder -> legal/finance reviewer (if term affects contract/accounting).

## Scaled-mode path

AE -> Deal Desk -> Finance + Legal approvers -> CRO/CEO (if above threshold).
