# Enterprise Packaging Decision Tree

1. Is buyer regulated/procurement-heavy? -> If yes, enterprise path.
2. Needs custom terms/security review? -> Require procurement packet + MSA/Order Form.
3. Needs complex implementation? -> Require implementation SKU.
4. ACV below threshold and high customization requested? -> decline or revert to standard plan.
5. No clear operator sponsor? -> do not pursue enterprise package.
