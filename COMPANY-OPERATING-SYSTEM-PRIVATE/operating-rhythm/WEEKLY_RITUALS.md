## Overview

This document defines the weekly operating cadence for Settler operations.

---

## Weekly Rhythm

### Monday: Week Start

**Time:** 30 minutes

**Activities:**

1. **Review previous week**
   - Check metrics from last week
   - Review any missed commitments
   - Note wins and learnings

2. **Set this week's priorities**
   - Top 3 priorities for the week
   - Block focus time
   - Schedule key meetings

3. **Review pipeline**
   - New leads/prospects
   - Customer health
   - Blockers to address

**Template:**

```markdown
# Week of [DATE]

## Wins Last Week

1. [Win 1]
2. [Win 2]

## Missed Commitments

1. [What was missed]
2. [Why it matters]

## This Week's Priorities

1. [Priority 1] - [Why]
2. [Priority 2] - [Why]
3. [Priority 3] - [Why]

## Blockers

1. [Blocker] - [What's needed]
```

---

### Wednesday: Mid-Week Check-In

**Time:** 15 minutes

**Activities:**

1. **Progress check**
   - On track for priorities?
   - Any emerging issues?
   - Need to reprioritize?

2. **Quick metrics**
   - Revenue this week?
   - Customer issues?
   - Pipeline changes?

3. **Adjust if needed**
   - Shift priorities
   - Ask for help
   - Escalate blockers

**Questions to Answer:**

- Are we making progress on top priorities?
- Any fires that need immediate attention?
- What's NOT getting done that should be?

---

### Friday: Week Review

**Time:** 30 minutes

**Activities:**

1. **Document decisions**
   - Log in `../decisions/` folder
   - Note rationale
   - Flag for review if needed

2. **Review accomplishments**
   - What got done this week?
   - What didn't?
   - Why?

3. **Prepare for next week**
   - Carry forward priorities
   - Schedule meetings
   - Block focus time

4. **Update tracking**
   - Metrics dashboard
   - Pipeline status
   - Project boards

**End-of-Week Checklist:**

- [ ] Decisions logged
- [ ] Metrics updated
- [ ] Next week prepped
- [ ] Accomplishments documented
- [ ] Blockers escalated if needed

## Decision Logging

### Friday Decision Review

Every Friday, review decisions made during the week:

**Questions:**

- Did we make any significant decisions?
- Are all decisions documented?
- Any decisions that need broader input?

**Decision Log Format:**

```markdown
# Decision: [Title]

**Date:** [Date]  
**Decider:** [Name]

## Decision

[What was decided]

## Rationale

[Why this choice]

## Alternatives

[What else was considered]

## Consequences

[Expected outcomes]

## Review Date

[When to revisit]
```

## Weekly Operating Questions

### Founders Should Ask Weekly

1. Are we closer to our goals this week?
2. What's the biggest risk right now?
3. What needs to change next week?
4. What should we stop doing?
5. What should we start doing?

### For Operators

1. Am I blocked on anything?
2. What decisions do I need from founder?
3. What can I decide myself?
4. What's going well that I should scale?
5. What should I delegate?
