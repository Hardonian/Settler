# Security and Procurement Escalation Matrix

| Intake type            | Primary responder | SLA target      | Escalate when                       | Stop condition                 |
| ---------------------- | ----------------- | --------------- | ----------------------------------- | ------------------------------ |
| Standard questionnaire | Security owner    | 3 business days | custom clause requests              | asks exceed supported controls |
| DPA/MSA redlines       | Legal owner       | 2 business days | liability/security changes          | uncapped/unsupported terms     |
| Architecture deep dive | Eng lead          | scheduled       | requests for unsupported guarantees | capability mismatch            |

Use explicit language: "supported", "supported with condition", or "not supported".
