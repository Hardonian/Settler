# Customer Diligence Data Room Index

## Include

- Approved contract templates
- Security questionnaire response pack
- Product security and tenancy evidence references
- Support and onboarding operating boundaries

## Redact or control-share

- Internal discount policy thresholds
- Internal risk register commentary
- Non-public architecture details not required for buyer diligence

## Never send casually

- Raw internal decision logs
- Unredacted incident retros containing other-customer details
- Any secrets/credentials or internal environment manifests

## Version discipline

Each shared artifact includes version date and owner.
