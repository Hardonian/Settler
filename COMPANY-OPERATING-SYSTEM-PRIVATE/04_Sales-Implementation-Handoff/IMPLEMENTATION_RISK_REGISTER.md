# Implementation Risk Register

| Risk                    | Trigger                | Mitigation                                | Owner        |
| ----------------------- | ---------------------- | ----------------------------------------- | ------------ |
| Data quality mismatch   | high exception rate    | data mapping workshop + sample validation | Impl owner   |
| Stakeholder drift       | sponsor unavailable    | formal weekly checkpoint                  | Sales/CS     |
| Scope creep             | unsold requirements    | contract/SOW boundary enforcement         | Founder      |
| Procurement delays      | legal/security backlog | packet pre-share + escalation             | Legal/RevOps |
| Integration instability | third-party API issues | fallback schedule + retry policy          | Eng          |
