# Time to Value Model

## Target journey

- Day 0-3: environment/data access
- Day 4-10: first trustworthy reconciliation and exception review
- Day 11-21: repeatable workflow embedded in operations

## Typical blockers

- Missing data owners
- Delayed procurement approvals
- Ambiguous success criteria

## Commercial implications

Longer TTV increases pilot risk, delays conversion, and increases support/implementation cost.
