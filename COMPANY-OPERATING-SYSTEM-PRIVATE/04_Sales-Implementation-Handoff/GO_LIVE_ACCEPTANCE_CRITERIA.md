# Go-Live Acceptance Criteria

## Must-pass checks

- Technical: data feeds functioning, reconciliation runs stable, exception workflow validated
- Commercial: signed contract in effect, billing activated, entitlements set
- Security/procurement: required diligence commitments complete
- Training: admin/operator training completed
- Support: support path and severity routing confirmed

## Explicit non-go-live reasons

- Open critical security/legal blockers
- Missing billing/entitlement setup
- Undefined ownership at customer side

## Launch exception process

Document exception, owner, risk, and temporary expiry in decision log before launch.
