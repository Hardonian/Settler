# Sales to Implementation Handoff

## Required fields

- Customer/legal entity + sign date
- Purchased SKUs and pricing terms
- Contract term, billing start, payment terms
- Success criteria and use-case scope
- Stakeholders: executive sponsor, admin owner, operator owner
- Technical dependencies and data sources
- Security/procurement blockers remaining
- Risks and mitigations

## Ownership matrix

- Sales owner: commercial accuracy
- Implementation owner: delivery plan + milestones
- CS owner: adoption plan and renewal signals
- Finance owner: billing setup validation
