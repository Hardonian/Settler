## Overview

This runbook guides the process for onboarding the first Enterprise customer.

---

## Pre-Enterprise Checklist

### Before First Enterprise

- [ ] MSA template ready (`/LEGAL/MSA_TEMPLATE.md`)
- [ ] DPA template ready (`/LEGAL/DPA_TEMPLATE.md`)
- [ ] Enterprise pricing defined ($1K-10K/mo)
- [ ] SOC 2 roadmap ready
- [ ] Enterprise support process

### Technical Readiness

- [ ] SSO/SAML testing complete
- [ ] Dedicated infrastructure provisioning ready
- [ ] Enterprise monitoring setup

---

## First Enterprise Process

### Stage 1: Initial Contact

- Founder-led research and personalized outreach.

### Stage 2: Discovery & Qualification (1-2 weeks)

- Discovery Call (60 min).
- Context and pain points (30 min).
- Position Settler value (15 min).

### Stage 3: Security Review (2-4 weeks)

- Answer customer security questionnaire (5 days).
- SOC 2 report (if available).
- Security practices presentation.

### Stage 4: Proposal & Negotiation (2-4 weeks)

- Solution design (architecture + integration map).
- Commercial proposal (custom price, 1-2yr term).
- SLA negotiation (99.99%).

### Stage 5: Legal (2-6 weeks)

- MSA negotiation.
- DPA (if required).
- Final signature.
