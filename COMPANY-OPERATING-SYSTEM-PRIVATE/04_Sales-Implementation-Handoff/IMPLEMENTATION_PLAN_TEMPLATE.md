# Implementation Plan Template

## Phases

1. Discovery + data readiness
2. Configuration + validation
3. Controlled go-live
4. Hypercare and stabilization

## Timeline model

- Standard: 2-4 weeks
- Enterprise: 4-8 weeks (procurement/security complexity dependent)

## Milestone gates

- Contract and billing complete
- Data source access complete
- Pilot/validation success passed
- Go-live checklist complete

## Escalation path

Implementation owner -> Founder -> contractual governance review.

## Anti-patterns

- Starting build before scope freeze
- Bundling net-new feature delivery into onboarding timeline
- Declaring go-live without support handoff completeness
