## Handover Process

### When Handing Off Work

1. Document current state
2. Explain context and rationale
3. Show the "why" behind decisions
4. Point to relevant docs
5. Leave clear next steps
6. Make yourself available for questions

### Handover Document Template

```markdown
# Handover: [Area] from [Name]

**Date:** [Date]
**Successor:** [Name]

## Current State

[What's been done]
[What's working]
[What's not working]

## Context

[Why things are the way they are]
[Key decisions and rationale]
[Important relationships]

## Known Issues

1. [Issue] - [Resolution if known]
2. [Issue] - [Resolution if known]

## Next Steps

1. [Action] - [Owner] - [Deadline]
2. [Action] - [Owner] - [Deadline]

## Resources

- [Doc 1]
- [Doc 2]
- [Person]

## Questions?

[Contact info]
```
