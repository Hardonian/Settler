# Customer Onboarding Operating Model

## Activation path

1. Kickoff and role alignment
2. Data/integration setup
3. First-value run and evidence review
4. Workflow adoption and governance handoff

## 30/60/90 expectations

- 30: first operational workflow live
- 60: exception handling routine in place
- 90: executive value narrative + renewal baseline

## Roles

- Customer admin: access/config ownership
- Customer operators: daily exception workflows
- Executive sponsor: outcome alignment and renewal sponsor

## Anti-patterns

- Heroic founder-only onboarding
- No customer-side owner
- Training skipped before go-live
