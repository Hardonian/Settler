# Support Tiers and Boundaries

| Plan       | Included support                      | Response posture               | Not included                     |
| ---------- | ------------------------------------- | ------------------------------ | -------------------------------- |
| Starter    | async support                         | best effort                    | implementation projects          |
| Growth     | priority async support                | faster business-hours response | unlimited advisory/custom builds |
| Enterprise | named support path + SLA per contract | severity-based response        | undefined custom development     |

## Urgency classes

- Sev1: production blocking
- Sev2: major degradation
- Sev3: functional issue with workaround
- Sev4: general questions/requests

## Founder exceptions

Temporary support upgrades allowed only with expiry date and logged exception.
