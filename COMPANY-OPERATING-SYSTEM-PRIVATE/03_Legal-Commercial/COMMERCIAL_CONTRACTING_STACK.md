# Commercial Contracting Stack

## Default stack

- Self-serve/standard: Terms + order confirmation
- Growth/enterprise standard: MSA + Order Form + DPA (if data processing required)
- Custom implementation/services: add SOW
- Pilot: pilot letter or pilot order form with explicit timebox

## When each artifact is required

| Scenario               | Required artifacts             |
| ---------------------- | ------------------------------ |
| Standard paid plan     | order form/checkout + terms    |
| Enterprise annual deal | MSA + Order Form + DPA         |
| Custom implementation  | MSA + Order Form + SOW         |
| Free/paid pilot        | Pilot terms + success criteria |

## Procurement sequence

Security packet -> legal paper exchange -> redline cycle -> signature -> billing setup -> implementation kickoff.

## Redline posture

- Keep deviations minimal and logged.
- Reject clauses that create commitments beyond product/control truth.

## Internal routing

Sales owner -> founder/legal reviewer -> finance review (billing/payment terms) -> final sign-off.
