# Commercial Policy Exceptions Register

Record every non-standard term using this schema:

| Date       | Account | Exception Type                          | Standard Policy | Approved Deviation | Risk Created | Owner | Expiry/Revisit Date |
| ---------- | ------- | --------------------------------------- | --------------- | ------------------ | ------------ | ----- | ------------------- |
| YYYY-MM-DD |         | discount/payment/security/support/other |                 |                    |              |       |                     |

Rules:

- No verbal exceptions.
- Every exception must have expiry/revisit date.
- Review register in monthly operating pack.
