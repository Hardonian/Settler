| ------------------------- | --------------------------- |
| Subscription fees         | Subscription revenue        |
| Usage overages            | Usage revenue               |
| Implementation fixed fees | Implementation revenue      |
| Professional services     | Services revenue            |
| Discounts/credits         | Contra revenue              |
| Sales tax/VAT collected   | Tax liability               |

| Support tooling           | COGS - support tools        |
| Contractor implementation | COGS - delivery contractors |
| Sales tooling             | Opex - sales & marketing    |
