# Procurement and Expense Approval Policy

| Spend type                   | Threshold        | Approval                     |
| ---------------------------- | ---------------- | ---------------------------- |
| Software recurring           | <=$300/mo        | function owner               |
| Software recurring           | >$300/mo         | founder                      |
| Contractor/consultant        | <=$5k engagement | founder                      |
| Contractor/consultant        | >$5k             | founder + written scope      |
| Security/compliance services | any              | founder + finance visibility |
| Travel/client delivery       | <=$1k            | owner                        |
| Travel/client delivery       | >$1k             | founder                      |

## Controls

- Every recurring spend needs owner, use-case, and 90-day review date.
- Spend tied to delivery/revenue should map to corresponding deal/opportunity.
- Retain invoices/contracts/approval artifact in a single folder.
