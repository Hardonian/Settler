Component Definitions ### App Shell - **Sidebar Nav:** Collapsible, 240px width. Icons + Labels. High contrast active states. - **Top Command Bar:** Global Search (Cmd+K), Breadcrumbs, Notifications, User Profile. - **Surface:** F1F5F9 background. Cards/Panels use White (#FFFFFF) with 1px border (#E2E8F0). ### Data Table Primitives - **Density:** Compact (32px row height) vs Default (40px). - **Header:** Sticky, sortable columns, filter icons in-header. - **Row States:** Default, Hover, Selected, Focused (Keyboard). - **Virtualization:** Required for >500 rows. ### Badges & Status - **Success (Matched):** Green text on light green bg. - **Warning (Unmatched/Stale):** Amber text on light amber bg. - **Danger (Failed/Breached):** Red text on light red bg. - **Neutral (Pending/Draft):** Gray text on light gray bg. - **Info (Processing):** Blue text on light blue bg. ### Interaction Elements - **Drawers:** Slide from right, 480px width (Desktop) or 100% (Mobile). Overlay backdrop. - **Modals:** Centered, 560px max width for forms. - **Buttons:** Primary (Filled), Secondary (Outline), Ghost (Icon-only). --- ## 3. Screen-by-Screen Expansion ### 1. Reconciliation Workspace (Expansion) - **Central Table:** Columns [Checkbox, Transaction ID, Source A (Stripe), Source B (Bank Ledger), Variance ($), Status (Badge), Owner, Age]. - **Evidence Drawer:** - **Header:** ID + Status + Assignee. - **Tabs:** Overview (Explanation Text), Timeline (Audit), Raw Data (JSON Diff). - **Actions:** 'Force Match', 'Flag for Review', 'Assign to Analyst'. ### 2. Exceptions Management (Expansion) - **SLA Countdown:** "2h 15m remaining" (Amber) -> "EXPIRED" (Red). - **Playbook Panel:** Sidebar panel with "Suggested Fix: Manual Ledger Entry" + Confidence Score (92%). ### 3. Matching Rules (Expansion) - **Condition Builder:** Nested logic: `IF (Source_A.Amount == Source_B.Amount) AND (Source_A.Date within 24h of Source_B.Date)`. - **Test Mode:** Side-by-side "Proposed Rule" vs "Current Results" showing match rate change. --- ## 4.
