# Customer Proof Standard

No case study, testimonial, ROI statement, or traction metric may be published until this standard
is satisfied.

## Pilot admission

- Named customer and accountable sponsor.
- Executed pilot agreement or order form.
- Defined systems, data scope, security boundary, and success criteria.
- Baseline period captured before Settler is introduced.
- Written permission for product telemetry required by the pilot.

## Minimum production scorecard

| Metric                 | Definition                                                              |
| ---------------------- | ----------------------------------------------------------------------- |
| Financial volume       | Currency-normalized value of records within the agreed scope            |
| Record volume          | Source and target records evaluated, excluding test data                |
| Deterministic coverage | Share resolved by deterministic rules without optional ML assistance    |
| False-match rate       | Sampled or fully reviewed incorrect matches divided by produced matches |
| Missed-match rate      | Known valid matches not produced divided by known valid matches         |
| Exception rate         | Unresolved exceptions per 10,000 evaluated records                      |
| Time to close          | Comparable elapsed time before and after deployment                     |
| Operator effort        | Measured human review time for the same workflow                        |
| Financial impact       | Recovered or prevented value supported by source records                |
| Reliability            | Completed scheduled runs divided by eligible scheduled runs             |

Every metric must include a date range, cohort, exclusions, source export, and calculation owner.

## Case-study release gate

- At least 90 days of production observation unless the study says otherwise.
- Customer reviews all facts and provides written publication consent.
- Quotes come from a real named person or are explicitly anonymous with the reason recorded.
- Results distinguish correlation from causation.
- No certification, uptime, or accuracy claim exceeds the observed scope.
- Finance or an independent reviewer reproduces monetary calculations.
