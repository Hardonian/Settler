# Diligence Index

This index reports evidence availability. A policy, template, or checklist is not proof that the
underlying event occurred.

| Area                          | Status                        | Acceptable evidence                                         | Current action                                                |
| ----------------------------- | ----------------------------- | ----------------------------------------------------------- | ------------------------------------------------------------- |
| Formation and governance      | Missing external evidence     | Filed formation documents, bylaws, resolutions              | Obtain counsel-reviewed originals                             |
| Cap table                     | Missing external evidence     | Current signed cap table and security ledger                | Establish authoritative system of record                      |
| Employee and contractor IP    | Missing external evidence     | Signed invention and IP-assignment agreements               | Audit every contributor                                       |
| Customer contracts            | Missing external evidence     | Executed order forms, MSAs, DPAs, amendments                | Populate contract register after first sale                   |

## Data-room admission rule

A document enters a buyer-facing data room only when it has:

1. a named owner;
2. an effective or observation date;
3. a source system or signed original;
4. a scope and explicit exclusions;
5. reviewer approval; and
6. no unresolved conflict with `EVIDENCE_REGISTER.md`.

Scenario models and templates remain internal and must be visibly labeled as such.
