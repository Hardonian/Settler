# Weekly Review Checklist

**Last Updated:** 2025-01-20  
**Status:** Revenue Bootstrap - Active  
**Purpose:** Weekly review checklist for founder operations

## Overview

This checklist helps you:
- **Review progress:** Assess week's performance
- **Identify issues:** Catch problems early
- **Plan ahead:** Plan next week's activities
- **Optimize:** Improve processes and results

**Philosophy:** Weekly reviews prevent monthly crises.

---

## Weekly Review Structure (2 hours)

### Revenue Review (30 minutes)
**Goal:** Assess revenue performance

**Review:**
- [ ] **MRR:** Current MRR vs target, trend
- [ ] **New Customers:** New customers this week, trend
- [ ] **Churn:** Churn this week, trend, reasons
- [ ] **Conversion Rate:** Pilot-to-paid conversion rate
- [ ] **Pipeline Value:** Total pipeline value, conversion forecast

**Questions:**
- Are we on track for revenue goals?
- What's driving revenue growth?
- What's causing churn?
- How can we improve conversion?

**Actions:**
- Identify revenue issues
- Plan revenue improvements
- Set revenue goals for next week

---

### Pipeline Review (30 minutes)
**Goal:** Assess pipeline health

**Review:**
- [ ] **Leads:** New leads this week, sources
- [ ] **Demos:** Demos conducted, conversion rate
- [ ] **Pilots:** Active pilots, conversion rate
- [ ] **Conversions:** Conversions this week, value
- [ ] **Forecast:** Revenue forecast, confidence

**Questions:**
- Is pipeline healthy?
- Are we generating enough leads?
- Are demos converting to pilots?
- Are pilots converting to paid?

**Actions:**
- Identify pipeline issues
- Plan pipeline improvements
- Set pipeline goals for next week

---

### Customer Review (30 minutes)
**Goal:** Assess customer health

**Review:**
- [ ] **Customer Health:** Health scores, trends
- [ ] **At-Risk Customers:** At-risk customers, interventions
- [ ] **Support Tickets:** Support volume, resolution time
- [ ] **Customer Feedback:** Feedback collected, themes
- [ ] **Churn Risk:** Churn risk signals, preventive actions

**Questions:**
- Are customers healthy?
- Are there at-risk customers?
- Are support issues resolved quickly?
- What feedback are we getting?

**Actions:**
- Identify customer issues
- Plan customer improvements
- Set customer goals for next week

---

### Product & Operations Review (30 minutes)
**Goal:** Assess product and operations

**Review:**
- [ ] **Usage Analytics:** Usage trends, patterns
- [ ] **Feature Usage:** Feature adoption, usage
- [ ] **System Health:** System performance, uptime
- [ ] **Costs:** Infrastructure costs, trends
- [ ] **Issues:** Bugs, errors, incidents

**Questions:**
- Is product usage healthy?
- Are features being used?
- Is system performing well?
- Are costs under control?

**Actions:**
- Identify product/ops issues
- Plan product/ops improvements
- Set product/ops goals for next week
