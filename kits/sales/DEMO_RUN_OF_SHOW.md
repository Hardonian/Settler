# Demo Run of Show

**Last Updated:** 2025-01-20  
**Status:** Revenue Bootstrap - Active  
**Purpose:** Structured demo script that converts prospects to pilots

## Overview

This demo script helps you:

- **Show value quickly:** Demonstrate value in 30 minutes
- **Address concerns:** Answer questions, handle objections
- **Move to pilot:** Convert demo to pilot signup
- **Build confidence:** Show Settler works for their use case

**Philosophy:** Demo is a conversation, not a presentation. Show, don't tell.

---

## Demo Structure (30 minutes)

### Opening (5 minutes)

**Goal:** Confirm use case, set expectations, build rapport

**Script:**
"Thanks for your time today. Based on our conversation, I understand you're spending [X] hours/month on reconciliation and dealing with [Y] issues. I'd like to show you how Settler can help. Does that work for you?"

**Agenda:**

1. **Quick overview:** What Settler does (2 min)
2. **Live demo:** Show Settler in action (15 min)
3. **Q&A:** Answer questions (5 min)
4. **Next steps:** Pilot offer (5 min)

**Questions to Confirm:**

- "What's your current reconciliation process?"
- "What systems do you need to reconcile between?"
- "What's your biggest challenge?"

---

### Quick Overview (2 minutes)

**Goal:** Set context, explain what Settler does

**Script:**
"Settler automates financial reconciliation between systems. Instead of spending 2+ days/month manually reconciling Stripe payments with Shopify orders and QuickBooks records, Settler does it automatically via API—completes in <1 hour, 99%+ accuracy, complete audit trail."

**Key Points:**

- **Problem:** Manual reconciliation is time-consuming, error-prone
- **Solution:** Automated reconciliation via API
- **Outcome:** Saves 20-30 hours/month, reduces errors, improves compliance

**Don't:**

- ❌ Go into technical details
- ❌ Show features they don't need
- ❌ Overwhelm with information

---

### Live Demo (15 minutes)

**Goal:** Show Settler working for their use case

#### Part 1: Console Overview (3 minutes)

**Show:**

- Developer Console dashboard
- API key management
- Usage analytics
- Recent activity

**Say:**
"This is the Developer Console. Here's where you manage your account, view usage, and access all features."

#### Part 2: API Connections (3 minutes)

**Show:**

- Connect Stripe API (example)
- Connect Shopify API (example)
- Connect QuickBooks API (example)

**Say:**
"Here's how you connect your APIs. One-time setup, takes about 5 minutes per system. Settler supports standard integrations—Stripe, Shopify, QuickBooks, PayPal, Xero."

**If they ask:** "Do you support [X]?" → "We support standard integrations. If you need custom integrations, we can discuss Enterprise options."

#### Part 3: Create Reconciliation Job (3 minutes)

**Show:**

- Create reconciliation job
- Configure matching rules
- Select data sources

**Say:**
"Here's how you create a reconciliation job. You select your data sources, configure matching rules, and run it. Takes about 5 minutes to set up."

#### Part 4: Run Reconciliation (3 minutes)

**Show:**

- Run reconciliation job
- Show progress
- Show results (matched/unmatched transactions)

**Say:**
"Here's the reconciliation running. This processes 10K transactions in about 5 minutes. 99.5% matched automatically. This would have taken 20 hours manually."

**Key Metrics to Highlight:**

- **Time:** 5 minutes vs 20 hours (95%+ reduction)
- **Accuracy:** 99.5% match rate
- **Transactions:** 10K transactions processed

#### Part 5: Results & Audit Trail (3 minutes)

**Show:**

- Reconciliation report
- Matched transactions (with confidence scores)
- Unmatched transactions (with reasons)
- Audit trail

**Say:**
"Here's the reconciliation report. You can see matched transactions, unmatched items, and a complete audit trail. You can export this as PDF or CSV for compliance."

**Key Points:**

- **Matched transactions:** High confidence scores
- **Unmatched items:** Clear reasons why unmatched
- **Audit trail:** Complete documentation for compliance

---

### Value Demonstration (5 minutes)

**Goal:** Show ROI, address concerns, build confidence

**Show:**

- Time saved calculation
- Cost savings estimate
- Accuracy improvement
- Compliance benefits

**Say:**
"Based on your volume ([X] transactions/month), Settler would save you [Y] hours/month. At [Z] per hour, that's [Cost Savings] per month in labor costs. Plus, you eliminate errors and improve audit readiness."

**ROI Calculation:**

- **Time saved:** [Hours/month] × [Rate/hour] = [Cost Savings/month]
- **Error reduction:** [Error rate] → <1% = [Error Cost Savings]
- **Total ROI:** [Cost Savings] / [Plan Cost] = [X]x ROI

**Address Concerns:**

- **"What if it doesn't work?"** → "14-day pilot, no credit card required. You can test it risk-free."
- **"What if we need help?"** → "Email support included, 24-48 hour response. Enterprise gets dedicated support."
- **"What if we outgrow it?"** → "Professional plan handles 1M+ transactions/month. Enterprise is unlimited."

### Q&A (5 minutes)

**Goal:** Answer questions, handle objections, build confidence

**Common Questions:**

**Q: "How accurate is it?"**
A: "99%+ accuracy for standard use cases. You can see confidence scores for each match, and review unmatched items."

**Q: "What if we need custom integrations?"**
A: "We support standard integrations. If you need custom integrations, we can discuss Enterprise options."

**Q: "What's the setup time?"**
A: "One-time setup takes about 30 minutes—connect APIs, create reconciliation job. After that, it runs automatically."

**Q: "What if we exceed limits?"**
A: "Starter plan includes 100K reconciliations/month. If you exceed, you can upgrade to Professional (1M/month) or Enterprise (unlimited)."

**Q: "What support is included?"**
A: "Starter includes email support (24-48 hour response). Professional includes priority support. Enterprise includes dedicated support with SLA."

### Close: Pilot Offer (5 minutes)

**Goal:** Convert demo to pilot signup

**Script:**
"Based on what you've seen, Settler looks like a great fit for your use case. I'd like to offer you a 14-day pilot."

**Pilot Offer:**

- **Full API access:** All features included
- **Unlimited usage:** No limits during pilot
- **Standard integrations:** Stripe, Shopify, QuickBooks, PayPal, Xero
- **Developer Console:** Full access
- **Email support:** 24-48 hour response
- **No credit card required:** Free to try

**What You'll Need:**

- API access to your systems
- Sample data (at least 1K transactions)
- 30 minutes to set up

**After 14 Days:**

- If you see value, upgrade to paid plan ($99/month Starter)
- If not, no obligation—pilot expires

**Next Steps:**

- "Would you like to sign up for the pilot now?"
- "I can send you the signup link, or we can set it up together."
- "When would you like to start?"

## Demo Best Practices

### Do's

- ✅ **Show, don't tell:** Demonstrate value, don't just describe it
- ✅ **Use their data:** If possible, use their actual use case
- ✅ **Address concerns:** Answer questions, handle objections
- ✅ **Be specific:** Use numbers, show actual results
- ✅ **Move to pilot:** Always end with pilot offer

### Don'ts

- ❌ **Don't overwhelm:** Keep it focused, don't show everything
- ❌ **Don't oversell:** Avoid hype, be honest about limitations
- ❌ **Don't ignore questions:** Answer questions, don't deflect
- ❌ **Don't forget to close:** Always end with pilot offer
- ❌ **Don't rush:** Give them time to process, ask questions
