# Governance

Settler is maintained by a core team of maintainers who review and approve changes.

## Decision Making

- Minor changes are approved through standard pull request review.
- Significant changes (architecture, security, or breaking behavior) require maintainer consensus.
- If consensus cannot be reached, maintainers will document the decision in the pull request.

## Roles

- **Maintainers:** Review and merge changes, set technical direction, and manage releases.
- **Contributors:** Submit issues, pull requests, and documentation improvements.

## Communication

Use GitHub issues and pull requests for decisions and discussions related to code changes. If GitHub Discussions are enabled, use them for broader design discussions and community support.
